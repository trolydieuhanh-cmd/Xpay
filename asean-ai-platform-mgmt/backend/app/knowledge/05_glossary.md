# Từ điển thuật ngữ dự án

| Thuật ngữ | Định nghĩa |
| --- | --- |
| **AI Platform** | Nền tảng dùng chung cho các công ty thành viên ASEAN Holding truy cập năng lực AI |
| **RAG** | Retrieval-Augmented Generation — kết hợp tìm kiếm với LLM để trả lời dựa trên tài liệu riêng |
| **LLM** | Large Language Model — mô hình ngôn ngữ lớn (Claude, GPT, Gemini, Llama...) |
| **Model Gateway** | Cổng thống nhất truy cập các LLM khác nhau, có router, quota, billing |
| **WBS** | Work Breakdown Structure — cấu trúc phân rã công việc |
| **MLOps** | ML Operations — vận hành, giám sát, deploy mô hình ML |
| **HITL** | Human-in-the-loop — có con người xem xét trước khi đưa output ra |
| **PII** | Personally Identifiable Information — dữ liệu cá nhân |
| **NĐ 13/2023** | Nghị định 13/2023/NĐ-CP về bảo vệ dữ liệu cá nhân của Việt Nam |
| **Prompt Injection** | Kỹ thuật tấn công thao túng LLM qua input |
| **Hallucination** | LLM bịa thông tin sai (dù đầu ra nghe hợp lý) |
| **Fine-tuning** | Huấn luyện thêm model trên dữ liệu riêng |
| **LoRA** | Low-Rank Adaptation — kỹ thuật fine-tune tiết kiệm tài nguyên |
| **Vector Store** | CSDL lưu embedding cho tìm kiếm semantic (Qdrant, pgvector...) |
| **Embedding** | Vector biểu diễn ngữ nghĩa của văn bản |
| **Prompt Caching** | Cache phần đầu của prompt để giảm chi phí input tokens |
| **SLA** | Service Level Agreement — cam kết chất lượng dịch vụ |
| **RAG-as-a-Service** | Cung cấp RAG cho các công ty thành viên như một dịch vụ |
| **Guardrails** | Cơ chế chặn LLM tạo ra nội dung không mong muốn |
| **Gate** | Điểm phê duyệt trong quản lý dự án theo Stage-Gate |
