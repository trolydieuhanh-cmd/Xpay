# XPAY Chat iOS Swift

Day la vi tri danh cho ban iOS native Swift. Giai doan hien tai uu tien Android native preview vi thiet bi test chinh la Android.

Nguyen tac khi bat dau iOS:

- Dung `URLSession` de goi dung API contract trong `docs/native-api-contract.md`.
- Luu token bang Keychain, khong luu plaintext trong file tuy y.
- Tach `NexaCore` C++/Swift bridge cho ma hoa, sync, call state.
- Khong tao database rieng cho tai khoan that tren client.
