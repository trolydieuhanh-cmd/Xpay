# Gateway XPAY

Gateway XPAY is the product website, QR payment portal, admin operating console, and license gateway for XPAY software products.

## Main Surfaces

- `/` - public website for `gatewayxpay.com`
- `/admin` - admin console for payments, customers, packages, activations, expiry, suspension, renewal, online users, and Excel export
- `/chat` - XPAY Chat license login surface
- `apps/xpay-chat` - rebranded Nexa Chat source copy, kept separate from the public sales/admin portal

## Local Run

```bash
npm install
npm start
```

Open `http://127.0.0.1:4187`.

## Email

Copy `.env.example` to `.env.local`, keep `.env.local` private, and set the Hostinger mailbox password there. The server sends first-login passwords from `admin@gatewayxpay.com` through `smtp.hostinger.com`; if SMTP is missing, messages are written to `data/outbox/` for local testing only.

## Security Notes

- Do not commit `.env.local`, `data/state.json`, or `data/outbox`.
- Admin-created first passwords are generated by the system, emailed to customers, and marked as must-change on first login.
- Admin users can activate/suspend/extend licenses but cannot set the customer's initial password through the UI.
